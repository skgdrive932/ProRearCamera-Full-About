# Pro Rear Camera

Custom Android rear-camera app foundation with a professional manual-camera UI.

## Features
- Rear camera only (no front-camera switch)
- Camera2 preview
- Exposure compensation (EV)
- ISO control when supported
- Shutter-speed control foundation
- Manual/auto focus foundation
- Flash Auto / On / Off
- GitHub Actions debug APK build

Manual camera controls depend on the Android device's Camera2 hardware capabilities. A production version should query and enforce each capability before applying a control.
